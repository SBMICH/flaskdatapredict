Cómo funciona

  1. Datos clínicos{{ n_pacientes }} pacientes reales y 30 variables por paciente.
  2. PreprocesamientoCada variable se lleva a una escala común (promedio 0, desviación 1).
  3. Entrenamiento70 % de las pacientes para aprender, 30 % para evaluar.
  4. PredicciónLa app aplica el mismo preprocesamiento y el modelo elegido.

Origen de los datos

Estudio retrospectivo de {{ n_pacientes }} mujeres con preeclampsia de inicio temprano (Yi et al., Annals of Medicine, 2022). El archivo disponible venía estandarizado y con {{ n_sinteticas }} filas sintéticas (SMOTE) para equilibrar las clases. Recuperamos las unidades reales con los promedios y desviaciones publicados en el artículo; las filas sintéticas solo se usan para entrenar, nunca para evaluar.

Limitaciones

  • Solo {{ n_pacientes }} pacientes: riesgo de sobreajuste y métricas inestables.
  • Las plaquetas y el edema se reconstruyeron de forma aproximada, y el orden de «edema» e «hipertensión» en el síntoma inicial se dedujo de las frecuencias publicadas.
  • Todas las pacientes tenían preeclampsia: no sirve para embarazos sin ella.
  • El FCM no está entrenado; se muestra como referencia.
  • Es un ejercicio académico: no sirve para tomar decisiones clínicas.

Preguntas frecuentes

¿Qué predice exactamente?

Si el bebé de una paciente con preeclampsia precoz tendrá restricción del crecimiento fetal (peso estimado por debajo del percentil 10 para su edad gestacional) o un peso normal. Es la columna C31 del dataset.

¿Qué modelo conviene usar?

En esta evaluación, SVM y la red neuronal obtuvieron la mayor exactitud balanceada. La regresión logística es más simple e interpretable. Usa «Comparar los 4 modelos» para ver si coinciden en un mismo caso.

¿Qué formato debe tener el archivo por lote?

CSV o Excel con columnas C1 a C30 y, si quieres medir la exactitud, C31. Puedes descargar una plantilla con cuatro filas reales.

¿Se guardan los datos que envío?

No. La app procesa cada petición en memoria y no guarda los valores ni los archivos.
